## Non-fatal warnings observed (flag for attention)

1. `[graph-drift] ws=confiar rig list failed: rigs postgres: error returned from
   database: column "git_connection_ref" does not exist`
   — the `confiar` tenant schema predates the `git_connection_ref` column. This
   is the gap that `68cb416` (per-tenant schema reconcile) targets; it is **on
   main but not in the running image yet**. Non-fatal: the drift daemon logs and
   continues. Should clear on the next deploy.

2. `[graph-drift] ws=default rig=gt_core skipped: ls-remote
   git@github.com:gt-core-labs/gt-core.git refs/heads/main failed: error: cannot
   run ssh: No such file or directory / fatal: unable to fork`
   — the image has no `ssh` binary, so the drift-reconcile daemon cannot
   `ls-remote` a `git@github.com:` SSH URL. Non-fatal (daemon continues), but the
   drift backstop for SSH-remote rigs is effectively inert in this image. Either
   the image needs an ssh client, or these rigs need HTTPS/GitHub-App remotes for
   ls-remote to work. **Not a regression from the .9 incident** — independent
   gap. Recommend a follow-up bead.
